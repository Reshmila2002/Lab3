# Team Portfolio Website - Lab Sheet 03

A responsive one-page portfolio site for the COSC 32133 / BECS 32263 Full-Stack Software Development lab.

## Run the project

Open `index.html` in any modern browser. No installation or server is required.

## Project files

- `index.html` - semantic page structure: header, hero, about, team, contact form and footer
- `css/style.css` - global styles, responsive layout, cards, form and dark-mode colour variables
- `css/header-footer.css` - sticky header, navigation, mobile menu and footer styles
- `js/script.js` - typing effect, mobile menu, dark mode, active navigation, footer year and form validation

## Lab features included

- Sticky responsive navigation and mobile menu
- Light/dark mode saved in browser storage
- Animated hero typing effect that respects reduced-motion settings
- Active navigation link as the visitor scrolls
- Validated contact form with helpful error messages and success feedback
- Current footer year generated by JavaScript
